# ボードゲーム朝夕刊

重量級ボードゲーム好き向けに、ボードゲームの情報を5時間ごとにまとめる紙面です。
Claude の定期実行（スケジュールタスク）が毎回調べて、公開済みの Artifact ページを同じURLで更新します。
チャット側で動いている「開発・無線 朝夕刊」と同じ仕組みです。

- 紙面: __ARTIFACT_URL__
- 発行: 毎日 2・7・12・17・22時ごろ（日本時間。実行開始は各時刻の10分前）
- 通知: 発行のたびに主な見出しと紙面URLをアプリに通知

## 紙面の構成

| 面 | 中身 |
| --- | --- |
| お気に入り追跡 | サイス、テラフォーミング・マーズ、SETI、オーディンの祝祭、ネメシス、バラージ、クラウドエイジ、DUNE の拡張・再版・新版・日本語版など |
| 重ゲー新作 | BGG の重さ（Weight）3.5 前後以上を目安にした新作・発売予定・話題作。人数・時間・重さと、好きなゲームとの相性（◎○△） |
| クラウドファンディング | Kickstarter・Gamefound・BackerKit・国内クラファンの重ゲー案件。締切カレンダー、集まった額、支援者数、基本プレッジ、日本発送 |
| 国内・日本語版 | 日本語版の発売・予約、国内出版社の発表、ゲームマーケット |
| コラム | 号の記事に関係するテーマの短い解説（ある号だけ） |

過去の号はページ下のバックナンバーから本文ごと読めます（最新25号＝約5日分）。

## ファイル

- `prompt.md` … 定期実行に渡している指示文の控え。追跡するゲームや面を変えたいときは、ここを直したうえで Claude にスケジュールタスクの更新を頼んでください。
- `page/index.html` … 紙面ページの元ファイル（創刊号の時点のもの）。公開中のページはこれを毎回書き換えて更新しています。
