# JRA 競馬 予測・期待値ベース買い目ツール

JRA の過去レース（新馬〜G1 の全クラス。G1/G2/G3 を含む）を集めて勝率を推定し、
オッズと掛け合わせて期待値の高い買い目を出します。

- **どう買えば回収率が高いか**: [`reports/strategy.md`](reports/strategy.md)（券種・人気・条件・買い方別の回収率）
- 予想の最新版: [`reports/latest.md`](reports/latest.md)
- 学習に使っていない期間での検証結果: [`reports/backtest.md`](reports/backtest.md)

## 仕組み

| 段階 | 内容 | コード |
|---|---|---|
| 1. データ収集 | netkeiba から結果・払戻・全券種の確定オッズ（重賞）・血統を取得。3 秒以上の間隔を空けた単一の取得列。取得元が HTTP 400（アクセス過多）を返したらその場で停止 | `keiba/scrape.py`, `keiba/netkeiba.py` |
| 2. 特徴量 | レース前に分かる情報だけで作成（下の 6 観点） | `keiba/features.py` |
| 3. 勝率モデル | LightGBM（勝ち・3 着内の 2 モデル）→ レース内で条件付きロジットにかけ、市場オッズと統合 | `keiba/model.py` |
| 4. 買い目 | 着順確率（補正付き Harville）から全券種の的中確率を計算し、期待値 = 確率 × オッズ で選別、1/4 ケリーで配分 | `keiba/betting.py` |
| 5. 予想 | 出馬表と最新オッズを取得してレポート出力 | `keiba/cards.py`, `keiba/predict.py` |
| 6. 回収率分析 | 券種・人気・レース条件・買い方（フォーメーション）ごとの回収率を、前半/後半の再現性と誤差幅つきで集計 | `keiba/strategy.py` |

### 予想に使う 6 つの観点

| 観点 | 主な中身 |
|---|---|
| 能力 | 馬の Elo レーティング（全体・芝ダ別）、走破タイム指数、上がり指数、獲得賞金、到達クラス |
| 近走 | 直近 5 走の着順、クラスの上げ下げ、間隔、過去の人気 |
| 適性 | 芝/ダート・距離帯・競馬場・回り・道悪での成績 |
| 騎手厩舎 | 騎手・調教師の Elo と直近 1 年の成績、コース別成績、コンビ成績、乗り替わり |
| 血統 | 父・母父の産駒成績（芝ダ別・距離帯別・道悪）と産駒 Elo |
| 展開・枠 | 脚質、同型の数、コースの前残り傾向、枠の有利不利、斤量、馬体重 |

レポートの各馬の ◎○△－ は、その観点が評価をどれだけ押し上げているか（SHAP 値）のレース内順位です。

### 期待値の考え方

- 期待値 = 推定的中確率 × オッズ。1.00 が損益ゼロ。
- モデルの誤差を見込み、既定では 1.15 以上の買い目だけを推奨します（`--min-ev`）。
- 的中確率が 0.5% 未満の買い目は、わずかな確率の誤差で期待値が跳ね上がるので対象外。
- 基準を満たす買い目がないレースは「見送り」と出します。

## 使い方

データ取得と予想は GitHub Actions で動きます（netkeiba へのアクセスが必要なため）。

| ワークフロー | いつ動くか | やること |
|---|---|---|
| `jra-data` | 毎週月曜 22:17 JST / 手動 | 前週末の結果・オッズ・血統を追加 |
| `jra-predict` | 金 20:23、土日 09:23・14:23 JST / 手動 | 重賞の出馬表とオッズを取得し `reports/` を更新 |

定期実行はこのフォルダがデフォルトブランチに入ってから有効になります。
手動実行は Actions タブ → ワークフロー → Run workflow。`jra-predict` の `grades` を `all` にすると全レースが対象です。

手元で動かす場合:

```bash
cd jra_keiba
pip install -r requirements.txt
python -m keiba.scrape results --from 2026-11 --to 2026-10   # 結果を追加取得
python -m keiba.pipeline                                    # 学習 + バックテスト + 回収率分析
python -m keiba.cards --grades G1,G2,G3                     # 出馬表とオッズ
python -m keiba.predict --bankroll 100000 --min-ev 1.15     # 予想レポート
```

## データ

```
data/raw/races/YYYYMM.csv.gz     レース（日付・コース・馬場・クラス・ラップ）
data/raw/results/YYYYMM.csv.gz   出走馬ごとの結果（着順・タイム・通過・上がり・単勝オッズ・馬体重など）
data/raw/payouts/YYYYMM.csv.gz   払戻
data/raw/odds/YYYYMM.csv.gz      重賞の全券種・全通りの確定オッズ
data/raw/pedigree.csv.gz         父・母・母父
data/cards/<race_id>.json        予想時点の出馬表とオッズのスナップショット
```

## 注意

- JRA の控除率は 20〜27.5% です。期待値がプラスに見える買い目でも、推定確率が外れていれば負けます。
  `reports/backtest.md` の数字を見て、賭ける額は自分で決めてください。
- 買う時点のオッズは確定オッズと違います。締切直前に大きく動くことがあります。
- 馬体重・馬場状態・出走取消は直前まで分からないので、直前の実行ほど精度が上がります。
- 取得元への負荷を避けるため、取得間隔（`--interval`、既定 3 秒）は短くしないでください。約 1.2 秒間隔では 1 時間強でアクセス制限（HTTP 400）がかかりました。
